Feed Animals is a Unity-based arcade survival game where players must dodge enemies a
pproaching from all directions and use a spacebar-triggered shooter to feed them. 
The game focuses on reactive gameplay, coin collection mechanics, and enemy AI behavior. 
It was a hands-on project that helped me deepen my understanding of 2D collisions, player input 
handling, and real-time spawning systems.
